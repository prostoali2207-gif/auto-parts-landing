# Elite-reference discovery — Spline / auto-parts landing

When visual taste, art direction, identity, UX or conversion depends on outstanding exemplars, use the current canonical research method:
https://github.com/prostoali2207-gif/professional-ai-agents/blob/main/architect/methodology/excellence-reference-discovery.md
This is a local usable fallback, not a different quality standard.

1. Define what excellence means for the decision: visual craft, branding/distinctiveness, task usability, commercial leads, or technical production. Never conflate views, awards, visual polish and proven outcomes.
2. Seek independent origins: credible expert juries/archives, original studios and credited authors, deployed category sites, case studies with appropriate evidence, neighboring elite fields (editorial, motion, industrial, product) and small expert practices. Generic SEO top lists are merely discovery leads.
3. Traverse project -> original artifact -> maker -> other works -> independent validation. Actually inspect live/mobile/desktop pages, motion or identity usage. Thumbnail, reputation or award alone does not verify elite quality.
4. Distinguish craft-expert, repeated-observed quality, outcome-evidenced and unverified; document original URL, date, medium, observation, limits and comparability. Never infer ROI or conversion from competitor ads or expensive-looking UI.
5. Admit normally 3–5 complementary task-fit entries; fewer are fine. Return source links, specific transferable mechanisms, what to adopt/adapt/reject/test, risks and anti-imitation boundaries. Do not fix an arbitrary search quota.
6. Design and implementation owners preserve commercial truth, real CRM request journey, mobile CTA and accessibility. UI Guard independently checks actual render. Stop on saturation and use field feedback; no full formal agent qualification.
