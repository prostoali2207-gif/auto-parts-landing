# Visual Fundamentals for Spline

Use this as the professional foundation for Visual Taste Agent. It complements, but does not replace, live-reference research.

## Source hierarchy
1. W3C/WAI/WCAG for accessibility constraints.
2. Apple HIG and Material 3 for contemporary UI craft, hierarchy, typography, color, adaptive layout, states and motion.
3. Classic design literature for enduring typography, grids, proportion, composition and visual literacy.
4. Current visually reviewed live references for contemporary taste.

Classic references: Robert Bringhurst — The Elements of Typographic Style; Ellen Lupton — Thinking with Type; Josef Müller-Brockmann — Grid Systems in Graphic Design; Donis A. Dondis — A Primer of Visual Literacy.

## Typography
Typography must handle legibility, hierarchy, voice and rhythm.
- Define roles: display, heading, body, label/metadata, CTA.
- Establish hierarchy primarily through size, weight, width, spacing and color before adding more typefaces.
- Minimize competing typefaces.
- Inspect line length, leading, tracking and density on actual renders.
- Avoid thin weights for small important text.
- Preserve hierarchy across responsive states and larger text sizes.

## Color
Color is a hierarchy and meaning system, not decoration.
- Define dominant field, primary foreground, supporting tones, action accent and semantic states.
- Check luminance/value contrast separately from hue.
- Never rely on color alone to communicate information.
- Do not reuse action color casually for noninteractive decoration if it creates ambiguity.
- Use saturation strategically; if everything is loud, nothing is dominant.

## Hierarchy
The eye should have a deliberate first, second and third destination.
Use scale, weight, value, position, whitespace, crop, overlap and motion when justified. The primary CTA must remain visually discoverable even in expressive compositions.

## Composition
Judge focal point, balance, alignment, proximity, continuity, figure/ground, directional flow, negative space, edge tension, crop and density rhythm. A grid is a tool, not a prison. Break it only when the break creates stronger tension, hierarchy or identity.

## Scale and proportion
Judge relationships, not isolated pixels: headline to viewport, headline to imagery, CTA to body copy, controls to touch ergonomics, section height to information density. Large type alone is not art direction.

## Spacing and rhythm
Spacing groups meaning and controls pace. Use proximity before adding borders/cards. Build rhythm through contrast: dense/quiet, large/small, image/typography, dark/light, compressed/expansive. Avoid identical container geometry and padding in every section.

## Grid and responsive composition
Mobile is not scaled desktop. Reconsider focal order, crop, alignment, density and wrapping at compact widths. Define how every signature idea transforms on mobile. User-adjusted text size and spacing must not cause loss of content or function.

## Imagery and art direction
Judge subject relevance, crop, focal point, perspective, lighting, contrast, texture and consistency. Images must belong to one visual world. Avoid generic automotive stock language. Abstract/generated work may be used only as art direction, never fake Spline proof.

## Shape and graphic language
Borders, radii, rules, icons, labels and geometry need coherent logic. Do not create cards just because content exists. Prefer one strong repeatable motif over many unrelated effects.

## Motion
Motion should clarify continuity, hierarchy, causality or emotion. Do not animate merely because a library makes it easy. Never delay action or reading. Respect reduced-motion preferences.

## UI craft
Inspect enabled, hover, focus, pressed, disabled, error and success states. Interactive elements must remain identifiable, focus visible, labels readable and feedback unmistakable. The request form must stay usable even when visually expressive.

## Accessibility
Treat accessibility as visual craft.
- sufficient foreground/background contrast;
- no information by color alone;
- identifiable controls;
- clear labels and feedback;
- headings and spacing that group content;
- adaptable layouts;
- text-spacing resilience;
- visible focus;
- sufficient non-text contrast where controls rely on borders or shape.

## Brand coherence
Typography, color, imagery, shape, spacing and motion should feel authored by one visual intelligence. Individually attractive elements from different visual worlds still fail if the page has no coherent character.

## Intentional rule-breaking
A rule may be broken only when the agent can state:
1. which principle is being violated;
2. why the violation strengthens hierarchy, emotion, identity, tension or memorability;
3. what usability/accessibility cost it introduces;
4. how that cost is controlled.

## Mandatory fundamentals pass
Before handoff inspect the rendered direction through:
`TYPOGRAPHY → COLOR → HIERARCHY → COMPOSITION → SCALE → SPACING/RHYTHM → GRID/RESPONSIVE → IMAGERY → GRAPHIC LANGUAGE → MOTION → UI STATES → ACCESSIBILITY → BRAND COHERENCE`

An exciting concept does not pass if typography, color, hierarchy or interaction quality are weak.
