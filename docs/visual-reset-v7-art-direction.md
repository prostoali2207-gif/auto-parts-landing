# Spline Visual Reset V7 — EXPLODED OBJECT

Status: `VISUAL TASTE: READY FOR FRONTEND`

## Why V7 exists
The current V6 render is commercially clear but the beige / black / orange packing-tape system has become the dominant identity. It now reads as an authored template rather than a fresh, high-impact visual world. This reset intentionally does **not** preserve V6 palette, packing tape, shipping label, barcode, route stripe, hero grid or packaging metaphor.

Functional request behavior remains unchanged.

### Transferable mechanisms
- **Scout / Lightship:** one dominant focal event, product scale, full-bleed confidence, controlled chapter changes.
- **Dust Moto / Infinite Machine:** the object itself can carry the visual identity; low UI chrome makes industrial form feel valuable.
- **teenage engineering:** engineered objects, sparse interface chrome and deliberate restraint create more character than decorative UI.
- **Nothing:** recognizable identity comes from a coherent graphic system, not from generic “premium” styling.
- **RIMOWA:** editorial whitespace and material close-ups can create perceived quality without dashboard structure.
- **A24 / Not Real / Found:** cultural/editorial composition can create surprise and memorability without adding product claims.
- **On:** campaign-scale media and strong type can coexist with a direct commercial path when navigation and CTA hierarchy stay simple.

### What V7 explicitly rejects
- CRM/dashboard visual language;
- V6 beige paper surfaces;
- V6 orange packing tape / route line;
- shipping labels, pseudo-barcodes, manifest cards;
- card grids, glass, generic SaaS sections;
- “premium black + gold”; 
- automotive HUD / racing / carbon-fibre clichés;
- decorative technical diagrams presented as factual evidence.

## Divergence result
The internal divergence pass explored industrial object, editorial, fashion, packaging, architecture, cinematic, archival, abstract, surreal, product-launch, cultural-poster, tactile/material, identifier-language, radical-typography and wildcard directions.

Three materially different finalists:

1. **EXPLODED OBJECT** — a sculptural abstract auto-part assembly separated into layers in space; dark electric field; acid signal action; strong kinetic typography.
2. **SIGNAL POSTER** — type-only cultural poster system with aggressive crop, oversized Cyrillic and high-saturation chapter fields; no automotive object.
3. **CHROME ARCHIVE** — museum/editorial object catalog: pale metallic field, black typography, macro material crops, near-zero decorative UI.

### Selection
`EXPLODED OBJECT` wins because it combines the highest magnetism and originality with the strongest direct connection to “find the right part”, while keeping the request form conventional and usable. The visual object is expressive art direction only; it must never imply that Spline stocks or guarantees the depicted component.

## V7 concept sentence
**Spline turns an unknown part into an identifiable object: the hero shows a mechanical assembly opened in space while the page progressively resolves vehicle → part → contact into one request.**

## Palette
The old beige/orange family is removed.

- Deep electric navy: `#08111F` — dominant hero / dark chapter field.
- Cold white: `#F4F6F8` — primary light surface.
- Graphite: `#101419` — text / structural dark.
- Signal acid: `#C8FF2E` — primary action and selective routing cue only.
- Electric cobalt: `#4F6BFF` — secondary expressive depth, never a competing CTA.
- Cool metal: `#BFC7D2` / `#727E8D` — decorative exploded-object surfaces.
- Error / success remain semantic and independent.

Accent budget: acid is scarce. It owns CTA / critical focal punctuation, not every label.

## Typography
Replace the current all-purpose Plex visual character.

- Display: `Unbounded` 600/700 — monumental, wide, authored Cyrillic; used for hero / chapter statements only.
- Body / controls: `Manrope` 400/500/600/700 — calm, contemporary, highly readable.
- Mono: existing IBM Plex Mono only for genuine VIN/OEM and restrained metadata.

Display must be treated as composition, with mobile-specific line breaks rather than scaled desktop wrapping.

## Hero
### Desktop ~1440
- Full first viewport is deep navy.
- Wordmark sits quiet in cold white.
- Hero copy occupies the left 50–58% with huge cropped display type.
- `запчасть?` receives acid signal emphasis, but not via an orange stripe.
- Right side is a large abstract **exploded mechanical assembly** built from layered vector/CSS surfaces: bezel, lens/ring, bracket, connector, fasteners.
- Object is partially cropped by viewport edge so it feels larger than UI.
- Fine cobalt guide lines are allowed as expressive spatial structure, but no fake measurements or technical facts.
- CTA is a solid acid block with dark text, visually isolated.
- On pointer hover, object pieces separate by a few additional pixels/degrees; on touch they remain in the already-exploded static pose.

### Mobile ~390
- Hero is recomposed, not stacked desktop.
- Headline takes first focus and uses 3 deliberate lines.
- Exploded object becomes a large diagonal crop behind/below the text and occupies meaningful visual mass.
- CTA remains in first-screen travel.
- No tiny utility copy; supporting sentence remains readable.

## Signature moment
The hero object visually “opens” on hover / pointer movement through coordinated transforms of a small number of parts. It must feel like one mechanical event, not independent floating animation.

`prefers-reduced-motion` freezes the object in its useful exploded pose.

## Process
Remove the V6 route line and huge serial-number strip.

Create one high-contrast light chapter:
- three steps live on one editorial field;
- each step has a large numeral, but numerals interact with the typography/object framing rather than sit on a line;
- a thin cobalt/graphite connector may establish continuity;
- each beat uses different spatial placement to create forward motion;
- on mobile it becomes a deliberate staggered vertical rhythm, not equal cards.

## Evidence / reset beat
Use a full-width acid field for the key truth:

`Не нужно знать точное название детали.`

The supporting explanation is smaller graphite text. No badge, proof, rating, inventory or pseudo-logistics motif.

This is the page's loudest color field and creates a memorable chapter break before the form.

## Request transition
Hard cut back to deep navy for the request intro, then resolve into a cold-white work surface.

The form should feel like the calm interior after the expressive hero:
- broad light surface;
- no nested cards;
- no CRM shell;
- no packing manifest metaphor;
- 3 clear groups, generous separators, strong numbering;
- labels and helper copy remain conventional and readable.

## Form controls
- Cold-white / near-white background.
- 1px graphite borders or strong bottom/edge structure.
- Square or very small-radius geometry; no pill fields.
- Focus uses cobalt + visible outer ring.
- Acid is reserved for primary submit, file action highlight and selected/confirmed microstate only where semantically clear.
- Upload remains a native file input wrapped in a large practical target.
- Error/retry/success semantics unchanged.

## CTA system
Primary CTA becomes acid `#C8FF2E` on deep/navy or graphite surface.

Rules:
- no hard black drop-shadow block from V6;
- short physical press / slight compression allowed;
- top CTA and hero CTA share one visual grammar;
- submit uses same grammar and remains dominant.

## Motion
- 1 coordinated exploded-object hover transition.
- restrained CTA press.
- restrained focus / success transitions.
- no scroll-jacking, generic fade-up sequence, parallax theatre or WebGL dependency.

## Responsive / accessibility
- deliberate 390 / 768 / 1440 composition;
- no essential meaning on hover;
- no horizontal overflow;
- 44px+ practical interactive targets;
- text contrast remains WCAG-compliant;
- form remains single-column on phone;
- object decoration is `aria-hidden`;
- reduced-motion behavior preserves the complete layout.

## Implementation deletion list
Frontend must remove or neutralize:
- `.packageEvidence`, `.packagePlane`, `.shippingLabel`, `.barcode`, `.packageTape` visual language;
- `.routeWord::before` tape treatment;
- `.processSequence::before` orange route;
- beige/off-white V6 root palette;
- old request threshold diagonal/tape continuation;
- V6 hard-shadow CTA style.

Existing semantic markup may be reused only when it does not force the old visual language.

## Functional non-negotiables
Do not change:
- `create-landing-request` endpoint;
- VIN OR make + model + year rule;
- part identification rule;
- photo validation;
- required contact;
- analytics events;
- failure preservation / retry behavior;
- confirmed-success-only state.
