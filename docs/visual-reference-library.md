# Spline Visual Reference Library

This is a taste library, not proof of conversion performance.

## Qualification
A reference is valid only after rendered visual inspection. README, source code, stars, awards or descriptions are not enough.

Preferred review: open render or reliable full-page/video capture, inspect first screens, scroll the page, check mobile/desktop where available, record transferable mechanisms.

Statuses: `VISUAL REVIEWED`, `CANDIDATE`, `REJECTED`.

## VISUAL REVIEWED

### Scout Motors
Live: https://www.scoutmotors.com/
Capture: https://www.lapa.ninja/post/scoutmotors/
Use: full-bleed product imagery, concise oversized messaging, strong section pacing, confident CTA integration.
Do not copy: lifestyle/reservation mechanics irrelevant to parts sourcing.

### Lightship
Live: https://www.lightshiprv.com/
Use: bold brand scale, oversized type over imagery, strong orange/neutral relationship, cinematic chapter changes.
Do not copy: luxury pacing that delays Request a Part.

## What to learn
- one dominant focal point;
- real scale contrast;
- typography as composition;
- full-bleed imagery or graphic objects;
- rhythm between dense and quiet acts;
- controlled overlap/asymmetry;
- CTA integrated into the composition;
- art-directed mobile;
- one memorable signature moment;
- confidence to remove weak UI chrome.

## Growth rule
Do not promote a `CANDIDATE` to `VISUAL REVIEWED` because it is popular or technically impressive. Promote it only after visual inspection shows a mechanism worth learning from.
