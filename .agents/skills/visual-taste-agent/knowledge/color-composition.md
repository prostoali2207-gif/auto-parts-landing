# Color, hierarchy and composition

Sources: Apple HIG Color and Design Principles, Material 3, WCAG 2.2, Gestalt principles, and classic grid/composition literature including Muller-Brockmann.

## Color roles
Do not begin with attractive hex values. Define dominant surface, primary foreground, secondary foreground, action/accent, separators, status colors and optional expressive colors. Each color needs a communication, hierarchy, brand or compositional purpose.

Use color consistently. Do not use one color for conflicting meanings or rely on color alone for essential state.

## Value before hue
Inspect in grayscale. If hierarchy disappears, hue is hiding weak value structure. Separate important information through luminance as well as hue.

## Dominance
A palette is not equal shares. Decide what owns the page, what supports, what punctuates. Accent loses power when everything is accented. Large deliberate color fields can create stronger memory than accent sprinkled everywhere.

## Saturation and temperature
Saturation controls energy and attention. Reserve strong saturation for intentional focal moments unless the concept deliberately uses an immersive saturated field. Judge neighboring colors, area and screen context rather than applying simplistic warm/cool formulas.

## Contrast
WCAG 2.2 generally requires 4.5:1 for normal text and 3:1 for qualifying large text. Treat this as a floor, not proof of quality. Check controls, states and text over imagery.

## Hierarchy
Hierarchy determines first, second and third attention. Use scale, value, contrast, position, whitespace, density, direction, shape, typography and imagery selectively. A squint test should expose the primary promise and action. Equal visual weight everywhere is failure.

## Composition
Composition arranges visual mass, void, direction and tension.

Balance need not be symmetric. Asymmetry works when masses, contrast and whitespace counterweight each other. Every major viewport needs a dominant focal event.

Whitespace is active shape. It can isolate, group, create tension or release. Empty space without purpose is simply emptiness.

Use Gestalt deliberately: proximity for grouping, similarity for related roles, continuity for scanning, common region for strong grouping, and clear figure/ground. Break these only intentionally.

Scale establishes importance and emotion. Large elements must earn their area. Do not make headlines enormous merely because it is fashionable.

A grid is an organizing instrument, not a cage. Establish alignment logic before breaking it. Off-grid elements feel authored only when underlying order remains perceptible.

Treat scroll as sequence rather than stacked sections. Vary compression/release, loud/quiet, image/type, full-bleed/contained as the concept requires. Avoid repetitive equal-padding card bands.

Viewport edges can create scale through crops, bleed and partial objects. Never clip essential copy or controls for effect.

## Failure modes
Reject random palette expansion, low-contrast premium gray, accent everywhere, purposeless gradients, decorative status colors, equal visual weight, arbitrary misalignment, meaningless whitespace, repeated card bands and scale without hierarchy.

## Render review at 390 and 1440
Check focal point, reading path, visual gravity, balance, meaningful whitespace, grouping, value hierarchy, color roles, scale, edge behavior, section rhythm, CTA prominence and whether grid-breaking feels intentional.
